# 快乐学 · 闯关学堂（儿童英语 / 语文学习平板 App）

一个**纯网页、可安装到平板桌面的儿童学习应用（PWA）**，覆盖英语（沪教版·牛津上海版 1–9 年级）和语文（人教版一年级拼音 + 二年级识字/课文），支持**闯关练习、语音跟读、听音选词、闯关测验、错词复习、家长看板**，并可**多儿童档案分开使用**。

无需编译、无需后端，浏览器直接打开即可。

---

## 一、功能特性

- **多学科**：英语（牛津上海版 1~9 年级）、语文（人教版一年级汉语拼音 14 课 + 二年级识字/课文 14 单元）。
- **四步闯关玩法**（每课都有，且**每课、每关都可直接挑战，无需逐级解锁**）：
  1. 📚 **学一学**：翻转动词卡 / 拼音卡，点卡片看中文 / 汉字，真人发音朗读。
  2. 🎤 **跟我读**：听发音后跟读，浏览器自动识别打分（国内可能降级为自检模式）。
  3. 👂 **听音选词 / 听音选拼音**：听发音选出正确单词（英语）或拼音（语文）。
  4. 🏆 **闯关测验**：选中文意思（英语）或选拼音（语文），按正确率评 1~3 星。
- **激励系统**：总星数、每关星级、过关庆祝动画、重置进度。
- **错词本 / 复习模式**：答错的词自动收录，可集中复习、标记「已掌握」。
- **家长看板**：查看总星数、错词数、各年级通关进度。
- **多用户档案**：多个孩子各用各的账号，进度、错词互不干扰；可添加 / 改名 / 删除用户。
- **离线可用**：添加到平板主屏后，断网也能学习（PWA 离线缓存）。

## 二、如何本地预览（推荐先用这个看效果）

> 语音识别（跟我读打分）需要在「安全上下文」下运行，所以建议用本地服务器，**不要直接双击 `index.html`**（那样跟我读会变自检模式）。

```bash
cd english-learning-app
python -m http.server 8000
```

然后用浏览器打开 `http://localhost:8000`（推荐 **Chrome / Edge**，安卓平板 Chrome 完美支持语音）。
本地预览**不影响平板**——平板用的是下面「安装到平板」得到的网址。

## 三、如何安装到平板（变成桌面 App）

### 方式 A：局域网临时玩（最简单，5 分钟）
1. 电脑上按上面启动 `python -m http.server 8000`；
2. 查电脑局域网 IP：`ipconfig` 找 IPv4（如 `192.168.x.x`）；
3. **平板连同一 WiFi**，浏览器打开 `http://192.168.x.x:8000`。

> ⚠️ 局域网是 http，**「跟我读」识别会降级为自检模式**（其他玩法、朗读正常）。

### 方式 B：添加到主屏幕（有图标、全屏）
平板能打开网页后：
| 平板 | 操作 |
|---|---|
| 安卓 Chrome / Edge | 右上角 ⋮ → **安装应用** / **添加到主屏幕** |
| iPad Safari | 底部分享 → **添加到主屏幕** |

桌面出现「快乐学」图标，点开即全屏独立窗口，孩子不会误触浏览器。

### 方式 C：部署到 https（推荐长期用，语音识别 + 离线全可用）
本项目已托管在 GitHub，开启 **GitHub Pages** 即可：
1. 仓库 `Settings → Pages → Source` 选 `Deploy from a branch` / `main` / `/ (root)` → Save；
2. 访问 `https://<用户名>.github.io/english-learning-app/`；
3. 平板用方式 B 添加即可——**「跟我读」打分可用，且断网也能玩**。
> 若仓库为 Private，Pages 仅登录同账号可见；想让家人直接打开请改为 Public。

## 四、多用户（多个孩子分开用）

首页顶部有一排**用户标签**，以及「＋ 添加用户」「⚙ 管理」：
- **切换**：点用户名标签即可，各自进度独立。
- **添加**：点「＋ 添加用户」，输入孩子名字（如「圆圆」「弟弟」）。
- **管理**：点「⚙ 管理」后可给每个用户**改名 / 删除**（至少保留 1 个，删除会清掉该用户进度）。
- 首次打开会自动创建默认用户「宝贝」。

每个用户的星级、错词本、通关进度都**单独保存**，互不干扰。

## 五、语音练习说明（重要）

- ✅ **不受影响**：TTS 真人朗读、闯关、卡片、听音选词/拼音（用本地朗读引擎，不需联网识别）。
- ⚠️ **「跟我读」发音识别**：走浏览器内置语音识别后端。在**大陆普通网络**下可能连不上 Google 后端，会自动降级为「自检跟读」（孩子录完音，家长陪确认）。
- 🔧 **想在国内真正给发音打分**：需接入国内 ASR（讯飞 / 百度 / 腾讯云），并配一个后端中转（`asr-proxy-server.example.js` 已给出示例骨架）。这是独立方案，需后端 + API Key。

```
    ├── storage.js          # 进度 + 多用户档案（localStorage）
    └── app.js              # 路由 + 闯关流程 + 四种玩法 + 复习 + 看板
```

## 七、如何扩展内容（不用改逻辑）

只改 `js/data.js`：

- **加学科 / 年级 / 单元**：按现有结构追加（英语用 `U()`，语文用 `P()` / `CU()`）。单元自动带 4 个闯关阶段。
- **加词 / 拼音**：往单元的 `words` 数组里加即可。
- **加跟读句子**：往单元 `sentences` 加句子（英语）；缺句子的英语单元已自动补简单句。
- 改完刷新页面即生效（若已装 PWA，需重新加载一次）。

## 八、技术栈

纯静态前端：HTML + CSS + 原生 JavaScript（无框架、无构建步骤）。
语音：`Web Speech API`（`speechSynthesis` 朗读 + `SpeechRecognition` 识别，可插拔国内 ASR）。
存储：`localStorage`（按用户档案隔离）。
安装：PWA（`manifest.json` + `sw.js`）。
